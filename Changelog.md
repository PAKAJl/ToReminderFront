# Changelog

## [2026-10-22] — UI-правки хедера, модалки и доски (2-я итерация)

### Исправлено
- **Пропадал логотип**: путь к картинке был абсолютным (`/images/...`) — при открытии страницы через `file://` (или при отдаче статики с корнем выше папки фронта) он resolving в корень диска/сервера и не грузился (`naturalWidth: 0`). Путь сделан относительным (`images/...`), добавлен `alt="ToReminder"`. Проверено: грузится и через `file://`, и через http.
- **Модалка не закрывалась после создания задачи**: сохранение ждало два сетевых запроса к медленному Turso (POST + повторный GET всего списка), окно висело открытым секунды. Теперь модалка закрывается мгновенно (замер: ~3 мс после клика «Сохранить»), карточка сначала появляется локально, затем синхронизируется с сервером в фоне; ответ сервера подставляется на место временной карточки, при ошибке — откат и уведомление.
- **Лишний перезачитывание списка**: `createNoteOnServer`/`updateNoteOnServer`/`deleteNoteOnServer` больше не вызывают `getNotes` после каждой операции — сервер возвращает созданную/обновлённую задачу, она маппится и заменяет локальную (один запрос вместо двух).
- **Дублирование уведомления** при удалении через trash-зону (раньше показывалось дважды).
- Убран дублирующийся блок `.header` в style.css.

### Изменено (CSS/style.css)
- **Активный токен виден полностью**: убраны `max-width: 280px` у обёртки и обрезка `text-overflow: ellipsis` у значения — длинный токен переносится на несколько строк (`word-break: break-all`); для состояния «Не установлен» добавлен класс `.token__value--empty`.
- **Layout хедера**: `.header__actions` — flex-строка с выравниванием (кнопка «Новая заметка» + панель токена), перенос строк на узких экранах; панель токена — две строки (дисплей токена / поле ввода с кнопками); кнопкам добавлен `white-space: nowrap` (текст больше не переносится внутри кнопок), ширина поля ввода 190px.
- **Колонки доски центрированы по горизонтали**: `.board { justify-content: center }` (+ `safe center` для узких экранов с горизонтальным скроллом); ширина колонки приведена к flex-basis (280px), высоты колонок/доски пересчитаны под новый хедер.
- Логотип уменьшен с 200×120 до 150×90 (`object-fit: contain`) для баланса хедера.

## [2026-10-22] — Интеграция с бэкендом и исправления

### Исправлено
- **Неверный адрес бэкенда**: был захардкожен `http://192.168.1.106:4200` (недоступен, порт не тот) → вынесен в константу `API_URL = "http://localhost:3000"` (rest.js).
- **Краш рендера**: `renderNotes()` передавал один объект в `renderAll()`, который вызывал `notes.filter(...)` → `TypeError: notes.filter is not a function`. Дублирующий сломанный `renderAll`/`renderNotes` из rest.js удалены — рендер выполняет `renderAll` из script.js через общий массив `notes`.
- **Несовпадение полей фронт/бэк**: бэк отдаёт `description/status/date/color/created_at`, фронт ждал `text/column/reminder/color/createdAt`. Добавлены функции маппинга `mapTaskToNote` (бэк → фронт) и `mapNoteToPayload` (фронт → бэк): `description↔text`, `status↔column`, `date↔reminder` (значение `-` = пусто).
- **Заголовок Authorization**: ранее без токена фронт отправлял литеральную строку `"null"`, токен шёлся без префикса → теперь `Bearer <token>` (или заголовок не отправляется вовсе).
- **`ReferenceError: module is not defined`**: удалён `module.exports` в конце script.js (не имеет смысла в браузере).
- **`saveNotes()` в демо-блоке** вызывал удалённую функцию → вызов убран.

### Добавлено
- **Создание проекта через API**: кнопка «Создать проект» вызывает `POST /api/projects` и сохраняет полученный с бэка токен в localStorage (раньше просто сохраняла введённую строку).
- **Кнопка «Ввести токен»** (`usetoken__btn` в index.html): проверяет токен через `GET /api/projects` и подключается к существующему проекту.
- **Создание заметки → `POST /api/tasks`** (модалка, кнопка «Сохранить»), после успеха список перечитывается с сервера.
- **Редактирование заметки → `PUT /api/tasks`** (модалка + drag&drop между колонками).
- **Удаление заметки → `GET /api/tasks/delete?id=`** (кнопка корзины и drop в trash-зону).
- Ошибки API показываются через существующие уведомления `showNotification` вместо `alert()`.
- Поиск заметки по id нормализован через `String(n.id)` (id с сервера — числа, из DOM — строки).

### Изменено
- Заметки больше не хранятся в localStorage (`noteflow_notes`) — сервер является единственным источником данных.
- Демо-заметки показываются только пока не подключён токен проекта.
- Файл `js.js` (сломанный мёртвый код, не был подключён в index.html) — удалён.
